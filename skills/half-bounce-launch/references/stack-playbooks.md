# Stack launch playbooks

Observed: 2026-11-22 across Rust native GPU, Swift/Xcode, and Tauri 2 desktop codebases on macOS 26. Apply only the track matching the target repository.

## 1. Rust native desktop apps (`GPUI`, `wgpu`, `egui`, `iced`)

- **Cargo workspace profile**: Place `[profile.release]` (`opt-level = 3`, `lto = "fat"`, `codegen-units = 1`, `panic = "abort"`, `strip = "symbols"`) in the **workspace root** `Cargo.toml` (member-crate profiles are ignored). Target-scope OS dependencies so macOS drops `wayland`/`x11` and secondary backends.
- **Two-stage Startup PGO + temporal `-order_file`**: Build Stage 1 unstripped with `-C symbol-mangling-version=v0`, `-C profile-generate`, and `-C llvm-args=-pgo-temporal-instrumentation`; run `>= 3` LaunchServices launches on a `Train.app` with `NSSupportsSuddenTermination = false` so `atexit` flushes `.profraw`; extract `startup.order` (`llvm-profdata order` with `show --all-functions --counts` + `nm -n` fallback); normalize Mach-O leading `_`; build Stage 2 with `-C symbol-mangling-version=v0` and `-Wl,-map`; remap crate disambiguators (`Cs..._`) with a fallback bucket cap (`<= 4`) so cold generics stay excluded; re-link with `-Wl,-order_file`; and A/B test `opt-level` `3`, `s`, and `z` (smaller `__text` often cuts `pre_main_plus_ls_ms` enough for `--pgo --opt-level z` to win both Run 1 and warm median).
- **Frame-1 critical path**: Start a background `Send` prefetch at line 1 of `main()`; keep empty-state init O(1); isolate `include_str!` asset decoding and secondary tabs behind `OnceLock` / `OnceCell`; move macOS menu setup and periodic animation timers to post-Frame-1 callbacks; keep background CLI probes (`Command::new("which")`) off UI event/render threads; keep custom fonts unless CoreText exceeds 25 ms.
- **Lifecycle parity**: Use `Cmd+W` close + Dock `on_reopen` on macOS and `on_window_closed` process quit on Windows/Linux.

## 2. Swift and Xcode (`AppKit`, `SwiftUI`)

- **Platform gate**: Check `SDKROOT` (`macosx` vs `iphoneos`) and `LC_BUILD_VERSION` platform first. Do not run `check_launch_hygiene.py --require-zero-exports` on targets with `TEST_HOST`/`BUNDLE_LOADER` or `AppIntents`. Never evaluate release launch hygiene on `ENABLE_DEBUG_DYLIB` stubs (`*.debug.dylib`).
- **Build settings**: Verify `SWIFT_COMPILATION_MODE = wholemodule`, `SWIFT_OPTIMIZATION_LEVEL = -O` (or benchmark `-Osize`), `DEAD_CODE_STRIPPING = YES`, `ENABLE_NS_ASSERTIONS = NO`, `LLVM_LTO`, and `MERGEABLE_LIBRARIES` when multiple dynamic internal frameworks exist.
- **App init & persistence store traps**: Move synchronous JSON file reads, multi-pass `JSONDecoder` + re-encode diff checks (`JSONEncoder(.sortedKeys)`), backup `URL.setResourceValues` writes, Keychain `SecItemCopyMatching` XPC calls, and `HKHealthStore()` creation off `@main App.init()` onto async `Task` or lazy properties. Guard root `View.body` against expensive frame-1 model construction, repeated schedule expansions, or dormant AI capability probes (`SystemLanguageModel.default.isAvailable`).
- **Obj-C `+load` and assets**: Inspect `__DATA,__objc_nlclslist` and `__objc_nlcatlist` (`objc_load_bytes`) for hidden `+load` initializers, audit `Assets.car` with `xcrun assetutil --info`, keep unused runtime frameworks from initializing early, and instrument real devices with `OSSignposter` + `MXMetricManager` (`MXAppLaunchMetric`).

## 3. Tauri, `WKWebView`, and SQLite hybrids

- **Synchronous `#[tauri::command]` main-thread blocking**: Non-`async` Tauri commands run synchronously on the AppKit main thread. Convert I/O, Keychain `Security.framework`, directory scans, and CLI probe commands (`claude --version`, `codex --version`) to `pub async fn` with `tauri::async_runtime::spawn_blocking`.
- **`.setup()` & startup persistence/SQLite**: Move non-Frame-1 work out of `tauri::Builder::default().setup(...)`. Defer full-pack SQLite SHA-256 verification and full-table validation until first query, add `immutable=1` / `PRAGMA mmap_size` for read-only resource DBs, replace O(N) directory JSON scans + double `serde_json::Value` decodes with single-pass index loading, move crash recovery `git`/`fsync` work off startup, evaluate `rusqlite` `bundled` vs system `/usr/lib/libsqlite3.dylib` (checking FTS5 parity), and note multi-thread Tokio/reqwest startup footprint.
- **Mach-O & embedded `frontendDist` bloat**: Because `tauri::generate_context!()` embeds `frontendDist` directly inside the Rust binary, disable production sourcemaps (`sourcemap: false` or hidden maps outside `dist/`) in Vite. Remove unused `crate-type = ["cdylib", "staticlib"]` mobile boilerplate in desktop `src-tauri/Cargo.toml`. Configure `bundle.macOS.minimumSystemVersion` in `tauri.conf.json` (plus `Info.plist` keys and `RunEvent::Reopen`), avoid blind `NSSupportsSuddenTermination = true` when cleanup/detach fences exist, and check whether `withGlobalTauri: true` can be dropped.
- **WebView parse & multi-process tracing**: Split secondary routes/editors/syntax highlighters behind `React.lazy()`, exclude test fixtures from production bundles, show interactive UI directly on Frame 1 instead of blocking on boot IPC waterfalls + skeletons, correlate `requestAnimationFrame` with Rust startup clocks, and include child `com.apple.WebKit.WebContent` processes in `xctrace`.
