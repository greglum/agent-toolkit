prompt, implementation, logo, benchmark dataset or media copied.

  Page reuse rights not established; no text or code copied.

Departure: preserve existing repository tools and gates, inspect off-graph consumers, and
keep generated feedback attributed until verified. Do not install Graphify, modify hooks,
choose providers, save model outputs as facts, or claim savings by default. The local
evidence adapter validates authored snapshots; it does not implement AST extraction,
community detection, semantic search, reflection or visualization.

Recheck when tool versions, graph direction/schema, extraction scope or backend behavior
change, or a repository trial contradicts a procedure. The dated research report carries
capability comparisons and trial evidence.
