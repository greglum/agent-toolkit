# Source and adaptation

Emil Kowalski's [Learn Taste](https://aiforui.dev/skills/learn-taste), observed
November 12, 2026, introduces carrying user corrections into future design work.
The [upstream procedure](https://github.com/emilkowalski/skills/blob/f7ce8c02d6e3c8f0d980a44c57bcc41a40254349/skills/learn-taste/SKILL.md)
is [MIT-licensed](https://github.com/emilkowalski/skills/blob/f7ce8c02d6e3c8f0d980a44c57bcc41a40254349/LICENSE).
This bundle uses original wording and examples. It extends the method to project
standards and skill procedures, supports automatic selection, and uses existing
task authority to decide whether a candidate can be written.

[Gloaguen et al.](https://arxiv.org/abs/2602.11988) found that repository context
files changed agent behavior and often increased costs in their coding trials.
That supports checking for duplicate instructions and routing to the existing
owner. Those trials did not evaluate this skill or design correction workflows.

Recheck after a missed correction, an unnecessary rule, or a selection failure
in a supported harness.
