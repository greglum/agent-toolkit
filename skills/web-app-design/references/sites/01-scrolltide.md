## What it offers

Scrolltide sells website prompts and source templates, with a strong focus on cinematic scrolling, motion, and visual identity. Its current public catalog also separates components, shader backgrounds, page sections, and application screens. The last group includes directory, finance, project, and analytics layouts. This is broader than a hero-only inspiration site, but its central offer remains visually striking websites. The homepage's catalog counts differed from the post's “300+” claim, so neither number should be treated as a stable selection criterion. [Public catalog](https://www.scrolltide.co/)

The FAQ describes React output, usually Vite, Tailwind, and Framer Motion, with some Next.js App Router templates. Raw source is included according to the owner. “Production-ready” is its marketing claim, not evidence that generated pages satisfy our app's contracts or quality gates. [FAQ](https://www.scrolltide.co/faq)

## Useful patterns and working method

Use this resource when a public product page needs a memorable identity, or when one carefully chosen visual moment could explain a product. Inspect the whole composition: where the headline lands, how the action stays legible, how imagery changes scale, and how successive sections establish rhythm. A restrained visual language can be useful even if we discard the animation.

For a working app, start with its UI-screen category and evaluate hierarchy and density. Do not import a cinematic landing-page shell into a queue, editor, or reporting task merely because the preview is attractive. Repeated work benefits from stable navigation, predictable scrolling, and low effort scanning. A shader or carousel should earn its runtime cost by supporting an actual user goal.

Suggested workflow:

1. Identify one task and one desired visual improvement before browsing.
2. Select a relevant screen or section and record the reference URL and three principles in original words.
3. Compare the principles with the existing tokens and primitives. Translate the useful parts into those owners.
4. If licensed source is supplied by the user, review its dependencies, interaction states, and provenance before adapting it.
5. Verify the actual application with realistic data, keyboard input, responsive layouts, and reduced motion.

## Access, code, and reuse

Access has material plan distinctions: the FAQ says 3D items require Yearly or Lifetime, while Monthly has a weekly limit on newly unlocked premium templates. Subscriptions renew; the FAQ describes digital sales as final. Recheck the live plan before any purchase rather than encoding prices in the skill. [Access and billing FAQ](https://www.scrolltide.co/faq)

The paid license permits personal and client websites. It prohibits redistributing templates or prompts, including modified versions, as a product or prompt pack; competing libraries and reuse of preview marketing assets are also restricted. Finished websites have separate use rights. Therefore this research library must contain analysis and links, not copied prompts, code, screenshots, or demo videos. [Terms, updated October 4, 2026](https://www.scrolltide.co/terms)

## Quality considerations and skill use

Analytical risks, not measured findings: scroll choreography can obscure content, motion can cause discomfort, GPU backgrounds can drain batteries, and large media can delay useful content. Require a static alternative, readable contrast over every visual state, and no forced motion on essential workflows. No accessibility audit or performance benchmark was run here.

Skill role: optional art-direction and motion reference after the app task and token system are understood. Recheck on plan/license changes, before downloading any paid item, or whenever the chosen preview's behavior becomes part of acceptance criteria.
