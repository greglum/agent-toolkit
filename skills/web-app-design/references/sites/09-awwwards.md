## Useful patterns and working method

Use Awwwards for intentional composition: a recognizable type hierarchy, the relationship between visual scale and content, section rhythm, and a narrative that makes a product understandable. Motion should explain a transition or support the story. A technique can be visually impressive and still be inappropriate for repeated work.

Marketing pages have more room for immersion than queues, reports, settings, and editors. For working apps, translate useful typography, alignment, and hierarchy into a calm interface with predictable navigation. Do not import WebGL, scroll choreography, or experimental cursors simply because a selected entry uses them.

Suggested workflow:

1. Define the task, audience, and intended impression before selecting references.
2. Compare two relevant entries and record the specific principle each demonstrates.
3. Follow the original site and creator credits when the behavior or implementation matters.
4. Adapt the principle through the app's existing tokens and components.
5. Verify actual workflows, keyboard input, responsive layout, reduced motion, and performance.

The award rubric should never replace repository acceptance criteria. Strong visual hierarchy can coexist with clear labels, stable focus, fast task completion, and appropriate density. The best application of this resource is to make those qualities feel deliberate rather than ornamental.
