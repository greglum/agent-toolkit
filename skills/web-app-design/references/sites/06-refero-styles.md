## What it offers

Refero Styles is a library of interpreted visual systems from product websites. Individual records expose palettes, typography, spacing, shapes, recommendations, and outputs such as `DESIGN.md`, CSS variables, design tokens, and Tailwind v4. Its homepage presents the collection as usable context for coding agents. That claim concerns visual context, not certification of a complete product design system. [Styles homepage](https://styles.refero.design/)

The inspected [Free Resume Builder style](https://styles.refero.design/style/41e65213-1c4a-41c4-b715-50427fa8926e) explicitly distinguishes normalized source measurements, interpreted roles, and reconstructed HTML examples. This matters: a reconstructed component is not the original site's production source, and an inferred color role is not an authoritative product contract.

## Useful patterns and working method

This resource is useful for explaining why a style feels coherent. Instead of collecting isolated hex colors, inspect how typography, surface separation, and accent restraint work together. For a working app, prioritize readable body and label roles over a marketing headline scale. A hero type size should not become the heading token throughout an editor or dashboard.

The [template guide](https://styles.refero.design/design-md/design-md-template) separates observed rules, deliberate project choices, and unknowns. Use that structure in our reference notes. Record the source and date, the app task, the useful visual principles, and what the capture cannot determine. Avoid pretending that a screenshot specifies focus, validation, responsive behavior, or permission states.

For marketing surfaces, Refero can supply varied type and color directions. For application surfaces, use its dashboard/form/settings collections as starting questions, then validate against real tasks. Preserve the repository's token names and component owners. Map a useful reference role to an existing token, rather than copying an entire generated token file and creating a competing system.

## Access, integration, and reuse

The inspected Styles records were public. Refero also promotes an AI connection, while its general terms distinguish free features from paid plans and feature-specific access. Exact prices and entitlement for every Styles export were not verified. There is no basis here for claiming the entire service is free or that an MCP entitlement is already available. [Styles access points](https://styles.refero.design/), [Refero terms](https://refero.design/terms-of-use)

The indexed official terms allow normal design and product work using learned insights. They restrict resale, redistribution, systematic extraction outside documented features, competing content libraries, and AI/ML dataset or evaluation use. Standard MCP/API access is for ordinary internal design work within applicable limits; product-level redistribution needs separate terms. Third-party logos, photos, fonts, and screenshots remain separate rights questions. No blanket open-source license for Styles exports was verified. This documentation contains original analysis and links, not copied exports. [Terms, indexed version updated August 3, 2026](https://refero.design/terms-of-use)
