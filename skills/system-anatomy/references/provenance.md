reviewed at `dbf697a527bbf7d358668e1557cb1e35ff725d46`, MIT, copyright 2026 Ryan.

surface; inspected published dial-indicator and exploded-engine images. Upstream examples,
geometry audits, WebGL and performance claims were not executed or independently verified.

Adopted ideas: let the represented mechanism shape the figure; coherent volume and occlusion;
one model drives visible state and readouts; inspect details as well as the overall image.

of fixed part counts; existing project tokens instead of a universal monochrome theme;
readable labels and evidence instead of a ban on callouts; opt-in tours, accessible local
controls, no-script explanation and synthetic-data labeling. No automatic kit import, browser
flag changes, remote font loads, 3D engine or fixed duration estimate.

code or substantial text must retain the upstream license and record the imported files and
revision. Reassess dependencies, file writes, networking and verification before executing
upstream helpers. The license does not establish suitability or visual quality.

Recheck these decisions when source, license, runtime, intended subject or delivery changes.
