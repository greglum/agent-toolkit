# Issues and requests

Greg Lum maintains these skills and tools. This repository publishes reviewed releases
for people who want to use them; development happens elsewhere, so pull requests are
not merged here.

Open an issue for a bug, a broken install, an unclear instruction, or a skill you would
find useful. Include the skill name, your agent (Claude Code or Codex) and its version,
what you asked for, and what happened. Run `sh scripts/verify.sh` first and include its
output if it fails.

Keep credentials, personal paths, private project details and raw agent transcripts out
of issues. For a security problem, use the repository's private vulnerability reporting
if it is enabled, or ask for a private channel before sharing details. No response time
is promised.
